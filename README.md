# LocaG: Motos On The Go

Quero que você faça um site de locação de motos. O nome é LocaG e tem uma logo. A logo eu só vou mandar depois. Eu quero que vocês se inspirem no site da Localiza. O site tem que ter a roleta de apresentação de moto, as motos aparecendo, o valor, tudo, como se fosse um site de locação. Tem que ter o lugar para poder fazer uma simulação de contratação. Tem que ter a aba de login. Tem que ter um programinha embaixo com inteligência artificial. Lembrando que isso vai ser só o front-end, nada disso vai ser funcional.
